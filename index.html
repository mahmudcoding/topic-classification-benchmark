Practical limits compared with an LLM

  • Limited room for text and labels. Input limits: GLiClass Mini/Ultra 1,024 tokens; GLiNER 4,096; BGE 8,192; mDeBERTa 512. GLiClass and GLiNER fit about 52 and 236 labels per message in this comparison. A shortlist can leave out the right label.
  • Multiple labels are unreliable. Selecting several labels needs a score threshold. We have not found a threshold that reliably separates correct labels from incorrect ones.
  • No built-in “not enough context” answer.
  • Limited answers. These runs return supplied labels and scores. They do not suggest new topics.
  • Fine details get mixed up. Models can confuse similar topics and select labels the text does not support. A high score can still be wrong.

A long-context LLM has room for more labels and rules. If none of the topics match, it can suggest a new one.

How we tested: We checked one highest-scoring label for each of 564 real Telegram posts, comments and group messages with at least one matching topic. No threshold was used. Uncertain choices were excluded. GLiClass and GLiNER used the closest labels that fit their input; BGE and mDeBERTa checked the full label list for all 564 messages.
